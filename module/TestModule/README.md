# TestModule

## Description

The Module is used to test Ping and Pong transmit messages for every 2 seconds

## Usage

Independent of other modules. User only needs to include the module in their role to use it.

## Consumes

Ping and Pong messages (consumed by the reactors)

## Emits

Ping and Pong messages (Emitted by the reactors)

## Dependencies

No Dependencies of any kind. This is for testing transmit and receive messages only.
