88  * @brief Opens (or re-opens) the ALSA capture device using the current configuration.

92  void setup_audio();
93 
94  /**
95  * @brief Runs the FFT-based whistle detection pipeline on one window of audio samples.
96  * Applies a Hanning window, computes the power spectrum, calculates the in-band

98  * @param samples One full FFT window of normalised float samples (size must equal cfg.fft_size).
99  */
100  void process_frame(const std::vector<float>& samples);
